## 2. 일일 루틴

```
07:05  수집   국내 시세·공시·수급, 미국장 마감·매크로 지표
07:07  작성   일일 리포트(요약·신호등·시각자료)
08:00  발송
```

- 사용 한도를 넘으면 억지로 쓰지 않고 그날은 조용히 건너뜁니다. 같은 날 중복 발송은 막혀 있습니다.
- 매수·매도·비중 규칙은 `ID@버전`(예: `KOSPI-CUT-1@v2`)으로만 인용하고, 바꿀 때는 버전을 올려 이력을 남깁니다.

## 3. 리서치 패널 (질문 하나를 검증하는 순서)

```
#1 팩트베이스(수집) → #2 팩트체크 → #3 분야별 분석 → #4-1 종합 → #4-2 레드팀(반박 3개 이상, 숫자 근거)
```

- 수집은 무료 모델, 검증·레드팀은 상위 모델, 분석과 최종 작성은 메인 에이전트가 맡습니다.
- 단계마다 앞 단계 결과를 **승인 / 수정요청 / 반려**하는 검토 루프를 거칩니다.
- 사실 한 줄마다 값·기준일·출처를 붙이고, 확실도를 **확정 / 유력 / 후보 / 약함**으로 표시합니다.

## 4. 검증 원칙

- **지어내지 않는다.** 못 찾으면 `[미확인]`으로 적습니다.
- **교차확인은 다른 제공자로.** 같은 원천을 옮긴 기사끼리 맞는 것은 교차확인으로 치지 않습니다.
- **출처 등급:** 1차 원문(공시·통계청·중앙은행·거래소) > 발표기관·주요 통신사 > 요약 사이트. 교차확인 결과는 출처 신뢰도 원장에 기록하고, 점수가 높은 출처부터 인용합니다.
- **확률엔 기저율 먼저.** 과거 비슷한 경우가 몇 번 있었는지(표본 수 포함)를 먼저 적고, 얼마나 조정했는지와 이유를 씁니다.
- **통계로 검증된 신호만 근거로.** 군집 제거, 순열 검정, 연도·국면별 일관성 검사를 통과한 신호만 씁니다.

## 5. 인과 지도 데이터베이스

경제 변수(노드) 사이의 **원인 → 결과** 연결과, 그 연결을 뒷받침하거나 반박하는 근거를 모은 SQLite DB입니다. 앱이 읽는 `graph.json`은 이 DB에서 만듭니다.

### 구조

| 테이블 | 내용 |
|---|---|
| `node` | 변수 이름, 범주, 연결된 시계열 |
| `edge` | 원인 → 결과, 방향(`+` 같이 / `−` 반대 / `±` 국면에 따라 다름), 등급, 조건, 메모 |
| `evidence` | 연결별 근거: 문헌·데이터 검정, 지지/반박, 시차, 효과 크기, 표본, 출처 |
| `log` | 등급·내용 변경 이력 |

### 등급 (선 색)

| 등급 | 뜻 | 현재 |
|---|---|---|
| **A 확실** (빨강) | 검증된 문헌이 지지 **그리고** 우리 데이터 검정도 정합 | 9 |
| **B 유력** (파랑) | 문헌·데이터·실적 추적 중 하나가 지지하고, 다른 근거가 보탬 | 29 |
| **C 후보** (회색) | 검증된 근거가 없거나 부분 지지뿐 | 195 |
| **D 논쟁** (점선) | 반박 근거는 있는데 강한 지지 근거는 없음 | 12 |

등급 규칙:
- 문헌 하나만으로는 B가 될 수 없습니다.
- 결과 쪽이 원인보다 먼저 움직이면(역방향 선행) 방향을 가릴 수 없어 '부분 지지'로 내립니다.
- 근거마다 방향(부호)이 다르면 '혼재'로 표시합니다.

### 범주 (점 색)

실물경제 · 물가·고용 · 정책·규제 · 금융·자산 · 대외부문 · 산업·AI

### 상관 vs 인과

- 데이터로 잰 상관계수(r)는 연결 옆에 따로 적습니다. 상관은 인과가 아니므로 앱에서는 청록 점선으로 구분합니다.
- 약한 상관(|r| < 0.2)도 DB에서는 지우지 않습니다. 화면 필터로만 숨깁니다.

### 최근 재검정 예 (2026-11-13)

| 연결 | 결과 | 판단 |
|---|---|---|
| 빅테크 AI 투자 → 한국 반도체 수출 | r 0.71 (2022년 이후 0.81, 겹치지 않는 구간 0.68, p=0.005) — 주로 **가격**을 통해 영향(가격 0.71 / 물량 −0.01) | 유지 |
| 외국인 순매수 → 코스피 | 같은 달 r 0.41, 다음 달 0.04 | 같은 달에만 연동, 예측력 없음 |
| 원/달러 → 메모리 가격 | r −0.01 (원화로 환산한 가격 기준 0.24) | 직접 인과 약함 |
| 경상수지 → 원/달러 | r ≈ 0 (외국인 증권 자금 −0.25가 더 큼) | 자본 흐름이 우세 |

## 6. 인과 지도 앱 사용법

**▶ https://sarkrk.github.io/causal-map/** · 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 없어도 마지막으로 받은 데이터로 열립니다.

| 동작 | 결과 |
|---|---|
| 배경 스와이프 | 전체 구조 3D 회전 (튕기면 관성) |
| 두 손가락 | 확대·축소, 이동 |
| 점 탭 | 관련 노드만 강조, 아래 패널에 **원인 → 노드 → 결과 관계도** |
| 관계도 칸 탭 | 그 노드로 이동 (연결을 따라 탐색) |
| `1단계 ⇄` | 원인의 원인, 결과의 결과까지 2단계 보기 |
| ☰ | 등급·범주·최소 \|r\| 필터, 상관선, 자동 회전, 흔들림 |
| **⟳** | **최신 데이터 받기** (이 버튼을 누를 때만 갱신) |

### 데이터 갱신 흐름

```
로컬 DB 튜닝(문헌 보강·데이터 검정·등급 조정)
  → causal_app.py publish  (graph.json 생성 → 이 저장소에 push)
  → 앱에서 ⟳ 누름          (버전이 다르면 새 데이터 적용, 같으면 "이미 최신")
```

자동 배포·자동 갱신은 없습니다. 갱신은 직접 요청할 때만 합니다.

### 파일

| 파일 | 내용 |
|---|---|
| `index.html` · `src/` | 앱 화면 (외부 라이브러리 없는 캔버스 그래프, ES 모듈: `engine` 그래프 계산 · `schema` 데이터 형식 검증 · `store` 화면 상태 · `render` 그리기 · `ui` 조작) |
| `test/` | 계산 엔진·데이터 형식·상태 단위 테스트 (`node --test test/*.test.mjs`) |
| `graph.json` | 데이터 (`meta.version`으로 갱신 여부 판단) |
| `sw.js` · `manifest.webmanifest` · `icon-*.png` | 홈 화면 앱·오프라인 지원 |
| `WORKLOG.md` | 작업 이력 |

## 7. 로컬 구성 (비공개, 참고용)

```
research/
├─ _framework/   운영 규칙(일일 루틴, 검토 규약, 출처 신뢰도, 자기개선 규약, 매매 규칙 rules.json)
├─ _tools/       수집·검증·인과 지도·발행 도구 (Python)
├─ _data/        시장 데이터, 인과 지도 DB(causal/graph.db)·시계열, 출처 원장
├─ theses/       논지 문서 26개 (반도체·AI, 코스피, 환율, 금리·지정학 등)
├─ daily/        일일 리포트
├─ web/          시각화 산출물 (이 앱의 원본)
└─ YYYY-MM-DD_<주제>.md   최종 보고서
```

주요 도구: `causalgraph.py`(인과 DB 관리·등급·문헌 적재) · `causaltest.py`(데이터 검정) · `causal_force.py`(상관 계산) · `causal_app.py`(앱 빌드·배포) · `sources.py`(출처 신뢰도) · `rules.py`(매매 규칙 버전 관리) · `collect_free.py`(무료 모델 수집) · `notion_publish.py`(보고서 발행)
